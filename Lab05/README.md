# Lab 05: Recursion

This lab draws a Koch snowflake using two approaches:

- A recursive implementation
- A non-recursive implementation using a stack

## Files

- snowflake.py: Contains the KochSnowflake class and both drawing methods.
- answers.txt: Contains the written answers for Parts 1 and 4.
- pseudocode files: Contain the pseudocode for the recursive and stack methods.

## How to run

From the Lab05 folder, run:

python3 snowflake.py
