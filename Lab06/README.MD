# Lab 6: Hash Maps and Trees

## Description

This lab creates a visual roster of the School of Engineering faculty.

Faculty information is imported from an Excel file and stored in a
dictionary using each professor's last name as the key. Thus a tree structure
is used to organize faculty members under their engineering programs.

## Files

- `engr_faculty.py`: Imports faculty data and builds the faculty tree.
- `faculty_visualizer.py`: Displays the tree and handles faculty searches.
- `tree_node.py`: Defines the TreeNode class and tree methods.
- `professor.py`: Defines the Professor class.
- `preferences.py`: Stores program constants.
- `faculty_list.xlsx`: Contains faculty information.
- `answers.txt`: Contains written answers for Parts 2, 3, and 4.

## How to Run

From the Lab06 folder, run:

```bash
python3 engr_faculty.py
